Manual de instalación

Clone el repositorio, levante los contenedores y tenga su clasificador de citas académicas funcionando en unos minutos, sin pasos manuales para el modelo.

Antes de empezar

  • Docker y Docker Compose v2 instalados y corriendo
  • Git para clonar el repositorio
  • Alrededor de 1 GB libre en disco — el checkpoint del modelo pesa ~420 MB
  • Los puertos 3000, 8000 y 5432 libres en su máquina

Instalación

  1. 1

    Clone el repositorio

    Ubíquese en una carpeta local, fuera de directorios sincronizados por OneDrive o Google Drive.

    # clonar y entrar a la carpeta del microservicio
git clone https://github.com/germarodr/MAIA4401_MicroProyecto.git
cd MAIA4401_MicroProyecto/citescope-api
  2. 2

    Configure las variables de entorno

    Es opcional: los valores por defecto ya funcionan para un despliegue local.

    cp .env.example .env

    Edite el archivo .env solo si necesita otra contraseña de base de datos, otro puerto de frontend o apuntar a otro checkpoint del modelo.

  3. 3

    Levante los servicios

    Un único comando construye las imágenes, descarga el checkpoint del modelo desde su almacenamiento y arranca los tres servicios en orden.

    docker compose up -d

    La primera vez tarda varios minutos: descarga el modelo, construye el frontend y carga los pesos en memoria.

    Nota: el checkpoint del modelo se descarga desde un enlace de almacenamiento en la nube debido a que su tamaño (~420 MB) supera el límite práctico de versionado de GitHub. Esta descarga es independiente del registro de modelos en MLflow: el proyecto no se conecta al almacenamiento en la nube de MLflow, ya que el entorno actual está desplegado sobre una cuenta de AWS Academy, cuyos parámetros de conexión son temporales y se renuevan en cada sesión de laboratorio.
  4. 4

    Verifique que todo esté saludable

    Los tres servicios deben quedar en estado Healthy antes de usar la aplicación.

    docker compose ps
  5. 5

    Abra la aplicación

    Con los servicios arriba, ingrese al frontend desde el navegador.

    http://localhost:3000

    Para consultar la API directamente: http://localhost:8000/health (estado del modelo) o http://localhost:8000/docs (documentación interactiva).

Si algo no arranca

  • model-init termina con un error de permisos

    El checkpoint en su almacenamiento de origen debe estar compartido como "Cualquier persona con el enlace, Lector". Confírmelo abriendo el enlace de descarga en una ventana de incógnito antes de volver a intentarlo.

  • api no encuentra el modelo y el proyecto vive en OneDrive

    Marque la carpeta model_artifacts como "Mantener siempre en este dispositivo" para que WSL no la vea como un archivo todavía no sincronizado.

  • Un puerto ya está en uso

    Cambie FRONTEND_PORT (u otro puerto en conflicto) en su archivo .env antes de volver a levantar los servicios.
